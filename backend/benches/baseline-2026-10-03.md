# Adapter decode and Order Book benchmark baseline

## Environment

- Host: `MBP-Pavel` (Apple Silicon arm64)
- OS: macOS 14.5
- Rust: `rustc 1.98.0 (88d9e12ae 2026-08-18)`
- Git HEAD: `5f209658628c6bc6be20989471feed5e6a797421`
- Working tree: dirty during this implementation; treat these numbers as a
  provisional baseline and compare only with later runs that record their own
  environment and source state.
- Fixtures: committed deterministic Binance depth/aggregate trade, Aster
  depth, and Lighter snapshot/update/delete frames in `fixtures/`.

## Command

```sh
cargo bench --manifest-path backend/benches/Cargo.toml --offline \
  --bench adapter_paths -- \
  --sample-size 10 --warm-up-time 1 --measurement-time 1
```

Criterion reports the range shown below. The harness separately performs a
10,000-operation warm-up, records 100,000 raw per-message latency samples in
hdrhistogram, then counts allocations in a separate 10,000-operation pass.
The raw latency timer overhead is included; no timer correction is applied.
